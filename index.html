recipe-guide backup

A private tool for one person: it copies the owner's own encrypted recipe backups to the owner's own Google Drive, using rclone. It is not a public service, has no other users and is not offered to anyone else.

It asks Google for one permission only, drive.file, which lets it see and change only the files and folders it creates itself. It cannot see anything else in the Drive.
