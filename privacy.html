Privacy policy

recipe-guide backup is a personal tool used only by its owner. It is not a public service.

What it accesses

With the owner's permission, it uses the Google Drive scope drive.file. This lets it create, read, change and delete only the files and folders that it created itself, in the owner's own Google Drive. It cannot see any other file in the Drive.

What it stores

Encrypted backup files of the owner's recipe collection. The files are encrypted on the owner's computer before they are uploaded, so Google holds only scrambled data. The login token that lets the tool reach the Drive is stored on the owner's computer only.

What it does not do

It does not collect, sell, share or send any data to anyone else, and it has no other users. It shows no adverts and uses no analytics.

Removing access

The owner can remove the tool's access at any time in the Google Account security settings, and can delete its backup folder from Google Drive.
